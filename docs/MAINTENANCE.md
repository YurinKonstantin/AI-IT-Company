# Поддержка актуальности документации

При закрытии фазы или заметном изменении UI/пайплайна обновите затронутые разделы.

## Чеклист

- [ ] `docs/FEATURES.md` — таблицы режимов / вкладок / агентов / CLI / биржи
- [ ] `docs/USER_GUIDE.md` — практика (режимы, промпты, пути данных); версия и дата в шапке
- [ ] Краткое оглавление / ссылки в `Readme.md` (без дублирования простыни)
- [ ] Сборка копирует `Docs\*.md` в output (csproj Content) — in-app **Справка** читает те же файлы
- [ ] Подсказки режима в Чате (`ModeHint`) согласованы с гайдом

## Карта «изменение → разделы»

| Изменение | FEATURES | USER_GUIDE |
|-----------|----------|------------|
| Новый режим / тип проекта | §3 | §2, §5–7 |
| Новый агент | §4 | §4 |
| Вкладка UI | §2 | соответствующие § |
| Биржа / скоринг | §7 | §10 |
| CLI | §8 | быстрый старт / EN summary |
| Пути данных / безопасность | §9, сводка | §11–12 |
